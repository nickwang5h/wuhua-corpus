## 重建与测试

在项目根目录执行：

```sh
npm run content:trial
npm test
npm run build
```

第一条命令仅重写本目录 `candidate.json`，不访问网络。输出包含来源、草稿版本、篇章、16 则正文、5 条分离的异文说明及署名。

导入器仅支持当前固定修订的结构，遇到未知模板、链接或篇章结构会报错，不会尝试删除所有标签来“清洗”文本。它保留繁体原字及标点，将 `另`/`另2` 模板主读放入正文、附读保留在 `variants`；移除导航、章节标记及录音信息；`[[詩經|詩]]` 只取显示文字。原始下载未改动；以上转换也是候选再分发时应保留的修改说明。每则暂作一个句子单元，不宣称完成句界校勘。

启用之前还需确定纸本底本与电子文本的权利范围、对照扫描校勘、补充独立编辑注解，并决定句界和简繁展示。若目标是纯公版底库，不应直接把这个候选的许可改为 PD，而应另找有版次证据的扫描或转录来源。
