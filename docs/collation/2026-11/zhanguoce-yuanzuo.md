# 战国策 鲍注“元作”原字混入正文：清理记录

底本：`src/books/zhanguoce.json`（corrections15 现状）。对校：`c13/ws/鮑本.json`（维基文库四库全书本鲍彪注，下称“四库鲍本”），`c13/ws/戰國策.json`（姚本系统，下称“姚本”）。

## 做法

1. 解析四库鲍本维基源码，把正文与 `{{SK notes|…}}` 注分开，记下每条注挂在正文第几个字之后。
2. 把本书西周至宋衛中山十卷的正文（只取汉字）与四库鲍本正文逐卷对齐（逐字 diff；先用两本之间高频互换的字对建了一张异体折叠表，消掉异体噪音）。对不上鲍本正文、只在本书出现的字，就是候选“多出的字”。
3. 逐个多出的字，看四库鲍本在同一位置有没有“元作X”（含“元並作”）注，X 是否正是多出的字：
   - 注就在此处、X 对得上：直接采纳（含异体，如 德/徳、䖏/處、丗/世、釡/釜、𢙣/惡）。
   - 此处无注，但同卷前文有同一词的“元作X下同 / 下並同 / 下章同 / 後並同”：按“下同”采纳（公仲中、沛市丘、列哀侯、蘇子秦、唐雎且、閔宣王、黄薔、長平羊、四五國、十百萬 等）。
   - 注写法不是“元作”而意思相同的，也采纳并在依据里写明：“元從水”（溢）、“元從女從后”（姤）、“元從寸”（尅）、“元從才從冓”（搆）、“元從汝從冓”（媾）、“元從口”（呡）、“元作御名”（宋高宗名構，本书写作媾/搆）、“元祚高”（祚为作之误）。
   - 四库注里的原字与本书所出字只是形近（士/七、山/由、到讀/至讀、鈶/鈆、僦/憱、抹/捄、幕/纂、掎/椅、鄮/貿）或四库缺字作□的（𦜴、鼻、揚），先查姚本：姚本原文正是本书所出的字，才采纳，并在依据里注明。
4. 对上的字：整段只有这个（些）字的，列入撤段；与鲍本正文同段的，写成 find/replace 删去。
5. 句读随动：撤段或删字后会出现段首标点、或丢掉句末标点的，另写一条把那个标点移到上一段末（或把上一段末的顿号改逗号）；纯属混入字自带、删后无须保留的标点，直接随段撤掉。每条都核过：撤删的每个汉字都是对不上鲍本正文的字（只有两处是对齐时同字取错了位置，人工确认无误：秦 0789“齊，”、秦 1006“與即”）。
6. `python3 tools.py check zhanguoce-yuanzuo.json`：items 319，bad 0。

## 上一轮遗留两处的定夺

- 燕 0235“燕欲報讎 於齊”：四库鲍本正文作“燕欲報讎仇於齊”，姚本作“燕欲報仇於齊”。“讎仇”连出两本不一，本书他处鲍本一律作“報讎”（燕 0185、0188），补“仇”反成“報讎仇”重语。定为只删空格（“報讎於齊”），已写进清单。
- 魏 0465“内得樓、翟、強以爲佐”：姚本“樓鼻、翟強”，四库鲍本“樓□翟强”，姚本录鲍注“『𢋛』，字書无此字。韓策作『鼻』，即『𢋛』也”。本书底本属鲍本系统，本书韓卷 0167 也作“樓𢋛”，所以补“𢋛”而不补“鼻”，同时去掉“翟、強”中间误加的顿号。同章同一人名还有三处脱了这个字：0452“所用者樓、翟強也”、0458“以輕樓，”、0459“樓欲合秦、楚”，四库鲍本都作“樓□”，一并补“𢋛”（0452 补在顿号前）。韓卷 0168 单独成段的“鼻”是“元作”原字，已撤；韓卷 0167“樓𢋛”保留。

已写进清单、但请人看一眼的（依据都写在 reason/evidence 里）：

- 四库注字与本书字形不同、靠姚本定的：東周 0224“七市”（四库注“元作士”，姚本“宮中七市”）；齊 0851“至讀”（四库“元作到讀”）；齊 0869“由”（四库“元作山”，同卷下文“猶〔元作由下同〕”）；楚 0523“鈆”（四库“元作鈶”）；楚 0655“憱”（四库“元作僦”，姚本“汗明憱焉”）；趙 0457“捄”（四库“元作抹”，姚本“齊乃捄趙”）；趙 0992“椅也”（四库“元作掎”，姚本“折王之椅也”）；魏 0917“纂繫”（四库“元作幕”，姚本“其自纂繁也”）；燕 0344“貿”（四库“元作鄮”）。

- 齊 0322“見閔王曰：子。”（删“宣”后）：下一段“子曰：”已撤，鲍本读作“王曰：子靖郭君之所聽愛夫”，这里“子”后的句号是混入时加的，建议去掉。
- 東周 0156“當他亡西周”：上一段“昌”已撤；“當”两本都无（姚本“宮他亡西周”），不是“元作”字，来源不明。
- 魏 0521“與蘇代秦”、0524“復東蘇代秦，”：“秦”是原字（姚本“蘇秦”），但四库鲍本魏卷这两处没有“元作秦”注（齊卷有“元作秦今並從代”），未改。
- 趙 0698“予”：姚本注“鮑本「子」原作「予」，又改為「子」”，是吴师道记的鲍本改字，四库鲍本无注，未撤。
- 秦 1140“儀”：鲍注“此上元有張儀字……故刪去”，是删字残留，未撤。
- 楚 0543“礛磻”：四库鲍本“被㔋磻〔無礛字…〕”，姚本“被礛磻”，“礛”是原字，但注不是“元作”，未改。
- 趙 0390“以未講”：鲍本只一“搆”，本书“講搆”重出，“講”不是注里的原字，未改。
- 趙 0365“成、”：当是“戍”的形误（原字“翟”没有混入），未改。
