# 日知录 对校候选裁决（rizhilu-collate）

候选 2037 处（形近 283、本书少字 154、本书多字 330、字不同 1270）＋末尾惯用字 159 组。对校本为维基文库《日知錄》；第二依据取维基文库《日知錄 (四庫全書本)》（下称四库）与《日知錄集釋》（下称集释），及本语料库《尚书》《诗经》《左传》《礼记》《史记》《汉书》《资治通鉴》，另核维基文库《北齊書》卷十七、《越絕書》卷四、韩愈《符讀書城南》、梁启超《情聖杜甫》。

要点：本书底本与集释同源（集释删去原注而成），删原注时常连带删去相邻正文（吕仲木、今即以、九少府、战长岸、叔父等），这类脱文据对校本与四库补。对校本与本书同一电子来源，也带假名、字母占位（ぜ、キ、YY 等），所以占位字的还原以四库、集释为据。
