# 文心雕龍 对校裁决（对校本：维基文库《文心雕龍》；第二本：NiuTrans/Classical-Modern 古文原文·文心雕龙，今人整理简体本）

说明：本书底本有大量刻本俗字（噐、㑹、𬒳、䖝、夲等），又有不少与通行本（黄叔琳注本一系）不同而文义可通的读法（“原道心，裁文章”“勲勞之家”“博聞爲饋貧之糧”“無者亦繁”“文思充被”等）。NiuTrans 本是今人校本，凡它与本书相同的一律不动；只有它与维基文库一致、而本书讲不通或明显是形近/脱衍时才改。维基文库录文常把校改字与原字并列（“摛摘”“媸蚩”“圜圓”“蕪無”“充光被”“諫譚”等），或把“疑作「性」”“李當作「孝」”“校作「一」”之类校语混入正文，这些都不是本书的错。

## 需人再看

- 章表 0001“循名課實，以爲本者也”：此处明显脱一字，对校本作“章”，NiuTrans 本作“文”，两本不一致，没补。
- 詔策 0001“明爲重也。周禮曰：師氏詔王。爲輕命。”：与通行本“明命為重也……明詔為輕也”不合，像是脱“詔”字、“命”字错位，两本互异，未动。
- 原道 0001“人實天地之心生。心生而言立”：两本都没有“人”和第一个“生”，可能是衍文，也可能是底本的另一种读法。
