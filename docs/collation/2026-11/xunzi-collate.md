# 荀子 对校裁决（对校本：维基文库《荀子》；第二本：维基文库《荀子集解》，光绪十七年王先谦刻本）

说明：集解正文以杨倞注本为本，多从谢墉、卢文弨校本，间据宋台州本改，并在注中列宋本、元刻异文。本书多与集解正文或其所引宋本一致；凡本书与这些版本相同、只是对校本据王念孙等校改的地方，一律当异文不动（下文“集解底本”即指集解正文）。集解维基文库录文“己”多作“已”（如“君子敬其在已者”“脩德在已”），不能作“己/已”的依据；这一类只凭对校本加“只有‘己’成词”的文义定，与《墨子》《近思录》已订“已/己/巳”同例。
