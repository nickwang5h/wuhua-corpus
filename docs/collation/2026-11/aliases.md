# 旧三书句子别名对齐（2026-11-27）

老子、论语、庄子的段落带有早期版本的句子编号（别名，`ws-…`）。从前 `content:correct` 改了段落正文、升了段落版本，却不动别名，于是 443 个别名（61 段）停在旧版本，存着旧字句和旧码点范围；其中 119 个的旧范围放到现行正文上已读出别的字。`scripts/migrate-aliases.ts` 把它们一次对齐：从历史取出该段在别名版本时的正文，与现行正文逐码点比对（最长公共子序列），把别名的范围映射到这句话在现行正文里的位置（含被改的字），版本改为段落现行版本，文字取现行正文在新范围的切片；旧别名记进历史，并加一条迁移指向现行别名，旧链接经 `successors` 可走到现行。之后 `content:correct` 每次订正都照此办理，`validateBooks` 要求每个别名都与段落同版本、文字等于切片、按序不重叠。

范围映射的规则：改动落在句内的随句；句界上新增的文字，以收尾标点（」。，等）开头的归上一句，否则归下一句；跨句界的替换按位置逐字对应（一换一时各归原句）。对齐后每段的别名仍首尾相接、覆盖全段，与导入时一样。

67 个别名文字变了（下表）；53 个文字未变、只因前面增删字而挪了位置（文末另表）；其余 323 个文字和范围都没变，只升了版本（迁移理由记“所在段落另处订正，本句文字未变”）。表中“旧句”是别名原存的文字，“新句”是对齐后的文字，“改动”是两者的逐字差异（∅ 表示空）。
