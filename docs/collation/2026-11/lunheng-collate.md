# 論衡 对校裁决（对校本：维基文库《論衡》；第二本：NiuTrans/Classical-Modern 古文原文·论衡，今人整理简体本）

说明：维基文库《論衡》是带校勘标记的今人校本，“（某）”是校删字，“〔某〕”是校补字（如“鄒（行）〔衍〕”“〔被〕累害者”）。本书是未经校改的旧刻本，凡本书与对校本括号前的原字相同、只是对校本据校勘补改的，一律按“对校本校补”不动。NiuTrans 本与维基文库本出自同一校本（同有“〔〕”补字，“已/己”写法也完全相同），独立性有限，所以“已/己/巳”一类只按文义定：只有一个字成词或讲得通时才改。维基文库还把本书的生僻字（洿、騄、翣、鸇、霣、驎、𦵔、蓂、觟𧣾等）丢掉，造成大量“本书多字”的假差异。
