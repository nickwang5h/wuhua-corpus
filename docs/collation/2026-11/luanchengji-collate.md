# 欒城集（luanchengji）对校裁决（corrections17）

## 对校本

- 底本本身来自维基文库《欒城集》（录入本）。另找到《欒城集 (四庫全書本)》（53 页，对上 92.5%），采用为对校本。
- 底本为简体录入后转繁的文本，繁简误转造成的错（复→復 应作覆、只→隻 应作祗、尝→嚐 应作嘗、干→幹、谷→穀、须发→須發、斗→鬥、胁/协相乱等）只在确实转错时才改。
- 第二依据：本书内证（覆育、祗服新命、祗率舊章、入治郎曹、丹旐、其容晬然以溫、祗候公人等）、本语料库《左傳》《尚書》《莊子》《史記》《元豐類稿》。
