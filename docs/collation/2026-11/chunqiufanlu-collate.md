# 春秋繁露 对校裁决（对校本：维基文库《春秋繁露》；第二依据：维基文库《春秋繁露 (四庫全書本)》）

对校本有一批成套的错字（“诈”作“軸”、“孰”作“庸”、“冰”作“在”、“枕”作“河”、“鸿”作“檻”、“蚩”作“送”、“丁”作“刃”、“浩”作“疾”、“湎”作“琨”、“熟”作“庸”、“豚”作“處”等），都是对校本自己的毛病，本书不误。

## 采纳

采纳｜卷一 0009｜厥辟去厥只→厥祗｜四库本“厥辟不辟去厥祗”；对校本“厥辟去厥祇”；“只”是转换误（“不辟”二字的有无属异文，不补）
采纳｜卷十三 0004｜物?疾（为仁义）→物疢疾｜四库本“物疢疾莫能為仁義”；对校本此处作“灾”
采纳｜卷十三 0004｜物?疾（偶天地）→物疢疾｜四库本“物疢疾莫能偶天地”；对校本作“灾”
采纳｜卷十六 0004｜山川神只立→神祇立｜四库本“孔子曰山川神祇立”；对校本“山川神祗立”
采纳｜卷十 0003｜深察王号的大意→之大意｜对校本“深察王號之大意”；四库本“深察王號之人意”（“之”同，“人”是四库本误）
采纳｜卷十六 0014｜天?亦止→天暒亦止｜对校本“未至三日，天暒亦止”；四库本“天大星亦止”，案语“他本無大字”，星、暒都是“晴”
采纳｜卷十六 0016｜尊实，●也→尊实，麷也｜四库本“尊實麷也”（原注一作“麰”）；对校本作“䵄”，是异体

## 形近类（逐条）

不改｜卷一 0009｜“只”对“祇”：已在采纳里改作“祗”
不改｜卷二 0004｜“未尝肯一与会同之事”，对校本“末嘗”：对校本误，四库本作“未嘗”

## 认真考虑过又放弃的

不改｜卷八 0007｜“园囿、萎●、台沼”：对校本是组字“萎外囗內巷”，四库本作“萎圈”，两本对不上，没把握
不改｜卷十三 0004｜“人之身首●而员”：对校本是乱码，四库本也是缺字，没把握
不改｜卷十六 0009｜“祭之以母?五”：对校本是乱码，四库本也是缺字码，没把握
