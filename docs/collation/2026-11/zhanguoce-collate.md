# 战国策 对校裁决（对校本：维基文库《戰國策》士礼居丛书本，即姚宏本；第二本：维基文库《戰國策》鲍彪注四库全书本）

本书底本是吴师道校注本系统的鲍彪本（四库本，guopop 转录，注文已去）。对校本是姚本，两本本来就有大量鲍、姚异文，所以“字不同”的绝大多数不是错字。第二本取维基文库《戰國策 (鮑彪注, 四庫全書本)》，它和底本同一系统，凡本书与四库鲍本一致、只与姚本不同的，都按鲍本原貌不动。四库本己/已不分、母/毋常混，所以这几个字上它不算独立依据，靠姚本加文义定。

## 成系统的问题（未改，需人决定做法）

底本把鲍注里的“元作某”（鲍彪改字后记下的原字）混进了正文。四库鲍本作“唐雎元作且”“列元作哀下同侯”“猶元作由”，本书成了“唐雎且”“列哀侯”“猶由可乎”。对校表里“本书多字”一类几乎都是这种：蘇子秦（17 处）、講媾（13 处）、唐雎且（11 处）、沛市丘、列哀侯、公仲中、桓宣子、五霸百、靳黈𪏘、韓珉呡、齊閔宣王、長平羊、黄薔、六五城、四五國、十百萬、猶由可乎、必不可克；尅攻等，表内约 60 处。另外，有些原字自成一段：全书只含一个字的段落有 471 段（如西周 0055“爲”、0090“中”），用四库鲍本的“元作”逐条对，命中两百多处。

改法应是删去混入的原字，保留鲍本正文（四库鲍本可以逐条作证）。但这是全书一律的结构清理，其中一大半要删整段，不在这份逐条清单的范围里，所以这份清单一处都没动。建议单开一轮：句内重字用 find/replace 删，单字段用撤段操作删。
