# 公羊传 对校裁决（对校本：维基文库《春秋公羊傳》；第二依据：本库《古文观止·宋人及楚人平》及其评注）

## 采纳

采纳｜宣公 0153｜大其平乎已也→平乎己也｜对校本“大其平乎己也”；《古文观止》同句，注“己、指華元子反，對君而言也”
采纳｜宣公 0153｜何大乎其平乎已→平乎己｜对校本“何大乎其平乎己”；《古文观止》“何大其平乎己”
采纳｜宣公 0154｜大其平乎已也→平乎己也｜对校本“故君子大其平乎己也”；《古文观止》同句
