# 鹽鐵論 对校裁决（对校本：维基文库《鹽鐵論》；第二本：NiuTrans/Classical-Modern 古文原文·盐铁论，今人整理简体本）

说明：本书底本与维基文库本出入很多，相当一部分是本书底本自成一读、文义可通的异文（少一虚词、语序不同、近义字）。NiuTrans 本与维基文库本几乎逐字相同，独立性有限，所以只在本书讲不通、或是明显的形近误字/脱衍时才改；本书读得通的，即使两本一致也不动。维基文库录文的“計－計”“（火索）”“丙”等是录入残留，不算本书少字。
