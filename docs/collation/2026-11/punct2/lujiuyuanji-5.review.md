# lujiuyuanji-5 标点通读复核

## 体例（供汇总统一）

- 引号用“”，内层‘’，再内层“”。“某曰”“某云”后接整句引语用冒号加引号；“故曰”“谓”“言”后只引一个词组或半句、作宾语的，不加冒号（如 故曰“出乎震”）。本份照此，未改。
- 书名号：书名、篇名都加，篇名单独加一对，不用间隔号（荀子《解蔽篇》、乾《文言》、《易》《杂卦》、《汉书》《食货志》）。卦名（晋、革、比、履、艮等）不加书名号。诗题拿不准的不加（刘定夫象山诗、少时自作大人诗、欧阳公赠梅圣俞诗）。
- 指书的“易”一律作《易》（原稿有的加有的不加，本轮统一）；“易道”“四营而成易”（变易义）不加。同一部书的 lujiuyuanji-4 也有“易之”“易者”不加书名号的地方，汇总时请一并看。
- 夹注【】里的文字可以加书名号，不跨出括号。

## 原稿“拿不准”各处的判断

都按原稿的读法定下来，理由如下：

- 0360 “与告子不动心……”：“与”字可能有误或有脱文，但标点只有这一种断法，保留。
- 0363 “临川张次房于厯子赋《归去来词》”：“于厯子”的意思不清楚，不断开是稳妥的，保留。**仍拿不准。**
- 0402 “一节一气共三十日有余分，为中分，中即气也”：读成“有余分为中分”也可以，两种读法意思差不多，保留。**仍拿不准。**
- 0439 “觉时已不如前，人所以乍出乍入”：“觉时已不如前”是说一觉察就已经不如从前，“人所以……”是总括的话，比读成“不如前人”顺，保留。
- 0460 “然吾非苛察，所攻兼自所谓学问者，自承当不住”：意思是“我攻的连那些自称有学问的人，他们自己也承受不住”，保留。
- 0467 “须看他成所以败所以是所以非处”：同意原稿，可能是“所以成”的倒文，不加标点。
- 0597 “问傅季鲁……若问二兄，恐不知先生学问旨脉。”曰：“固是……”：原稿读作季鲁答话、先生应“固是”，说得通，保留。**仍拿不准**（说话的人是谁看不出来）。
- 0603 “归精舍坐。四拜，问之”：读作“（有人）就这次四拜来问他”，保留。**仍拿不准。**
- 0612 “因提宫昨晚所论事”：保留。**仍拿不准**（“提宫”指什么不清楚）。
- 0644 “心都起了，不知如何在。”求“道徳成而上……”：保留。**仍拿不准。**
- 0670 《庄子》引文、“庄子。”、小经两句的分属：原稿的读法（“庄子”指上一句的出处，“势阻则谋，计得则断”是先生作的小经，意思像庄子）说得通，保留。
- 0683 “‘终万物始万物’而不与，乃是隂事将终、阳事复始，艮”：保留。**仍拿不准。**
- 0479 “问扬云”：同意，是先生问包扬，引号收到“做个人”为止。
