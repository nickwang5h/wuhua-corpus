# wangwenchenggongquanshu-3 通读复核

## 体例（便于和 -1、-2、-4 汇总）

- 引号外层“”，里层‘’；书名号《》，并列书名之间不加顿号（《文録》《传习録》）。
- “某曰”后用冒号加引号。例外：作者自述、自评的“曰”不加引号，照原加标点的人的处理保留：1177 邹守益“记曰：”（记内已有两层引语）、1200 钱德洪“叙言曰：”、1247 湛若水“读某状云云，曰：……”“甘泉子曰：……”。旁人的话（或曰、人或告曰、甘泉子闻之笑曰等）都加引号。
- 匾额、院名、书院名用引号的照原样（名曰“报功”、题曰“仰止”），不统一成不加。
- 注文【阙】照原样，标点不跨进【】。

## 读了多少

63 段全部按书中顺序从头到尾通读，约 4.9 万字。另外用脚本扫了：十五字以上没有标点的片段（91 处，逐处看过，都是官衔加人名、长定语，不用断）、引号书名号配对、“。”，”这类句末标点落在引号外的。

## 改动：7 处，涉及 5 段

| 类型 | 处数 |
|---|---|
| 1250 段原有标点改正 | 3（删顿号 1、引号收尾 1、排比一致 1） |
| 断错（兼语与谓语断开、问号断开反诘句） | 2 |
| 漏断 | 1 |
| 引号体例前后不一 | 1 |

逐处（改前 → 改后）：

1. 1250（原有标点）：又以湖、广二省之兵方合 → 又以湖广二省之兵方合。“湖广”是一个省，同段“移文湖广两司”、1249 段“湖广廵抚都御史秦公金”可证；下句“候二省夹攻尽絶”也说明“湖广”是二省中的一个。
2. 1250（原有标点）：亦须亲往勘破”，率其麾下 → 亦须亲往勘破。”率其麾下。引语收在句号后，叙述另起。
3. 1250（原有标点）：自大庾县穏下入，县丞舒富帅兵千余 → 自大庾县穏下入；县丞舒富帅兵千余。五路进兵并列，其余各路之间都用分号，只有这一处用逗号。
4. 1250（加标点的人新加）：命副使杨璋、叅议黄宏，监督各营官兵 → 命副使杨璋、叅议黄宏监督各营官兵。“命某某监督”是兼语句，不能在兼语后断开。
5. 1157：鼔舞天下之人至于今日不怠者，非雷霆之震？前日之龙塲，其风霰也哉！ → ……不怠者，非雷霆之震，前日之龙塲，其风霰也哉！“非……也哉”是一个反诘句，问号把句子从中间截断了；照应上文“郁极而轧，雷霆奋焉……则向之风霰为之也”。
6. 1153：人一能之已百之，人十能之已千之，必率是灵 → 人一能之，已百之，人十能之，已千之，必率是灵。用《中庸》成句，按原句读补断。
7. 1247：或曰：其且进且沮，使公不得入辅乎？ → 或曰：“其且进且沮，使公不得入辅乎？”。同篇另一处“或曰：“八峒掩袭村落以为功……””加了引号，这里统一。

## 1250 段原有标点：看过、没改的

这段原来有 213 个标点，逐个看过。除上面三处外，还有几处分号用得偏重，但不算错，没改：“及午，雨霁；各兵鼓奋而前”“赴军门投降，随众立效；意在缓兵”“我兵已据险，从上下击；贼不能支”。如果要求严格，这三处可以改成逗号。

## 加标点的人记的“拿不准”：我的判断

- 1149“刘道、刘弼、刘、王舜韶”：“刘”后面是私用区缺字，按人名断开，同意。
- 1147“又惧师聨无所，树艺不固”：同意，没有更好的读法。
- 1177“果畴而仰应，又畴而止之？”：同意（“畴”作“谁”讲）。“其上曰大极云”“稍离奔骛，黙悟真”（1220）：文字疑有脱误，保持他的处理。
- 1191“笠官郎署”：断句不受影响，同意。
- 1236“王氏自汉吉祥至祥览”：疑有讹倒（王吉、王祥、王览），定不了，保持不断。
- 1238“《易春秋説》”：作一部书标，同意（1238 段两次出现都这样写，又和“《周礼考正》”并列成两部书）。
- 1245“若将抄没之为，姻族皆震撼”：同意。
- 1247“是水也以浅见测渊谋也”：读不通，保持不断。
- 1249“流刼三省。【阙】 等官请调”：同意。
- 1250“皆自上江西捷音疏，仍分兵四路追蹑”：疑“自”后脱“首”之类的字。不改字就断不开，保持他的处理。

## 仍拿不准的（我新看到的）

- 1249“明年还，广信谒一斋娄先生”：也可以读成“明年还，[过]广信，谒一斋娄先生”。底本没有“过”字，按现字保留他的断法。
- 1147“孔子《易》有太极，是生两仪”：这句是撮述《系辞》的意思，不是直引原文，所以没加引号。

## 疑似错字

他列的那些（已/己、軬/輋、徙/徒、桷冈/桶冈等）我同意都属于“疑”，没改字。我认为确凿、有两样独立依据的：
- 1250“闻复破桷冈”当作“桶冈”：同段前后都作“桶冈”，1247 段两处也作“桶冈”。
- 1245“次守又，赵出”当作“守文”：1242 段作“次守文，郡庠生”，1245 段前后文排行也对得上（守仁、守俭、守文、守章）。
- 1238“曽祖纲性常兴其弟”的“兴”当作“与”：1234 段作“弟秉常、敬常并以文学知名”，1245 段写法同。“兴”是“與”的形近讹字，句子原作“性常与其弟秉常、敬常俱以文学显名国初”。
