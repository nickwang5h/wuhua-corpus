# wangwenchenggongquanshu-2 通读复核

## 体例（便于和 -1、-3、-4 汇总）

- 外层引号用“”，里层用‘’；书名号用《》；【】注文不动，标点不跨进【】。
- 并列书名之间不加顿号（《竹轩稿》《江湖杂稿》、《大学》《洪范》）。例外：0842“韩文、《楚辞》、《隂符》、《参同》之属”里有不是书名的“韩文”，维基文库《王陽明集》卷21也作顿号，照旧。
- “某曰”后一般用冒号加引号。例外有两类，都保留：
  1. 原文自带单个引号的四段（0997 遗书甘泉、1020 与尚谦书、1028 答舒栢／刘侯、1037 书壁文字和答顾东桥书节文），原有引号所引的是信里的一句话，加标点的人保留了它们的层级（双引号），外层只用冒号，不再加引号。我核过维基文库，这几处原有引号的位置都对（1020 除外，见下），所以没有把它们改成单引号再加外层引号。汇总时如果要全书统一成“曰：“……‘……’……””，这四段要把原有的“”改成‘’，再补外层引号。
  2. 节引、转述不加引号：0893“疏以……”、“琼奏以为……”，1095“臣等尝为守仁计，曰：……”、“臣则曰：……”，0985“罗洪先《赠女兄夫周汝方序》畧曰：……”（跨段，加不了）。
- 官职加人名的长名单：不同的官职之间用逗号，同一官职下的几个人之间用顿号（0902、0944、1083）。0915 那份名单原文就已经全用顿号，原有标点不改，所以照旧。
- 按语用“按：”（0837、0889、0946、0976、0995、1093）；0893“按勅谕有曰：”和 0849“按《同志考》：”后面紧接所据的文献，照旧不另加冒号。

逐处（改前 → 改后）：

1. 0889：若非粘泥贴网亦自主张末得 → 若非粘泥贴网，亦自主张末得。条件分句和主句之间要断开，原句有十二个字不带标点。
2. 0851：诸如此类，皆落落难合，其后思之既久 → 诸如此类，皆落落难合；其后思之既久。徐爱《传习录》引言写的是前后两层意思；本库 chuanxilu 卷上 0066 作“始皆落落難合；其後思之既久”。
3. 0954：临江知府戴徳孺、袁州知府徐琏、赣州知府邢珣、瑞州通判胡尧元、童琦、南安推官徐文英、赣州都指挥余恩、新淦知县李美， → 临江知府戴徳孺，袁州知府徐琏，赣州知府邢珣，瑞州通判胡尧元、童琦，南安推官徐文英，赣州都指挥余恩，新淦知县李美，。后半截“泰和知县李楫，宁都知县王天与，万安知县黄冕”的逗号是原文自带的，而前半截加的是顿号，同一份名单两种写法；另外“胡尧元、童琦”都是瑞州通判，全用顿号就看不出来。现在统一成：不同的官职之间用逗号，同一官职下的人之间用顿号。
4. 0958：命太监张永、张忠、安边伯许泰、都督刘晖率京边官军 → 命太监张永、张忠，安边伯许泰，都督刘晖率京边官军。理由同上：张永、张忠都是太监，许泰是安边伯，刘晖是都督。
5. 1020（原文自带的单个闭引号）：与尚谦书曰：“谓自咎罪疾，只缘轻傲二字。”足知用力恳切 → 与尚谦书曰：谓“自咎罪疾，只缘轻傲二字。”足知用力恳切。“谓”是先生转述尚谦来信，不在引语之内；维基文库《王陽明集》卷05《寄薛尚謙》作“承喻：“自咎罪疾，只緣輕傲二字累倒。”足知用力懇切”，引号也是从“自咎”开始。原有的闭引号位置是对的，没动。
6. 1028（原有逗号保留，另补一个逗号）：随其虚实寒热而斟酌补泄之要，在去病而已 → 随其虚实寒热而斟酌，补泄之要，在去病而已。原文“补泄之要，”的逗号是自带的，但“斟酌”后面没断，读起来成了“斟酌补泄之要”。这句出自《与刘元道》，维基文库《王陽明集》卷05作“而斟酌加減。調理補泄之要，在去病而已”，主语是“补泄之要”。在“斟酌”后补一个逗号，原有逗号不动。

## 引经核对（用本库）

- 0832“如好好色，如恶恶臭”：daxue 0003，起止都对（《大学》原文先“恶恶臭”后“好好色”，年谱照它自己的顺序引用，没改）。
- 0842“居处恭，执事敬，与人忠”（lunyu 13-19）、“克己复礼”（12-1）、“万物皆备于我，反身而诚，乐莫大焉”（mengzi 尽心上 0004，原文“我矣。反身”）、“学问之道无他，求其放心而已”（告子上 0028，原文后面还有“矣”）、“先立乎其大者，而小者不能夺”（告子上 0035，原文作“则其小者弗能夺也”）：引文止于年谱引到的地方，引号都对。后两句和原文字面不同，是象山的引法，维基文库卷21也这样加引号。
- 1020“生斯世也，为斯世也，善斯可矣”：mengzi 尽心下 0061，起止对；“非之无举，刺之无刺”没加引号，是化用，可以。
- 1037“虽有天下易生之物，一日暴之，十日寒之，未有能生者也”：mengzi 告子上 0026（原文“物也”），对。“大臣格君心之非”：离娄上 0030 作“惟大人为能格君心之非”，引的是意思，照他的处理加引号。“答顾东桥书”节文和“拔本塞源”论：对 chuanxilu 卷中 0018、0019、0060–0063 逐句看过，断句和本库一致；年谱是节本，字句少了不少，只按现有的字断。
- 1046“吾有知乎哉？无知也。”：lunyu 9-8，对。
- 1065 四句教：chuanxilu 卷下 0306、0312，起止都对。
- 1083“绥之斯来，动之斯和”：lunyu 19-25，对。

## 他标“拿不准”的：我的判断

- 1616“传职賔賔，羲以賔賔之寅而賔日，传以賔日之寅而賔賔也”：我同意。“不曰日，乃阳之属，为日，为元……”读起来像脱了字（比如“而曰阳”），不改字就没有更好的断法，保持他的处理。
- 1614“中凝外完，内缺门若，合流洄，髙岸屏塞”：定不了。“流”和“洄”之间其实还有一个私用区缺字（U+EC6B，四库本也是图片字），他的 replace 里保留了，所以实际是“合流□洄”，讲不通的原因可能就在这个字。保持他的处理。
- 1630“不大声色而政令行肃，观向一新”：同意。和上句“不费财力而事修于旬月之间”对仗，“观向一新”是结果。
- 0944“屈致，皷众，株连富民”：同意。
- 0946“时钦凌等攻围”：保持不断。“钦”可能是 0944 提到的余钦，“凌”可能是凌十一，但没有把握。“令济、光等亲人”：同意。
- 1095“事下本兵，持之；户部复请覆勘”：同意。“持之”是兵部压着不办。
- 1122“请卜，得鼎二之上，吉”：同意，没有更好的读法。
- 0849《同志考》：同意加书名号。
- 0893“疏以……”、“琼奏以为……”不加引号：同意，这是转述。
- 1109“卢王之徒”“卢王降卒”：同意，不拆开。
- 0915“珂知，既喜诺”：保持。如果“既”是“即”的误字，可以读成“珂知，即喜诺”，断句一样。

## 仍拿不准的（我新看到的）

- 0723“则亦大臣之才也已。而于此独不以大臣许之者”：维基文库卷30下作“則亦大臣之才也；已而於此，獨不以大臣許之者”。我认为“也已”收句更合八股的语气，保持他的断法，汇总时可以再看一眼。
- 0944“期以八月十五日因入试官吏生校举事”：可以理解成趁八月十五日乡试、官吏生员入场时起事，没有加断，保持原样。
- 0958“是月疏免江西税，益王、淮王饷军，留朝觐官……”：这是九道疏的事由，“益王、淮王饷军”是不是也属于“免”的范围不能确定，保持他的处理。
- 0985“世宗登极，诏将释，前已得疾，后五日卒于狱”：也可以读成“诏将释前，已得疾”，意思差不多，保持。

## 疑似错字

他列的 13 条我都同意只算“疑”，不改字。我认为有两样独立依据、可以算确凿的：
