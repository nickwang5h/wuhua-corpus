# lujiuyuanji-3 标点通读复核

## 体例（供汇总统一）

- 引号用“”，内层‘’（如 0303 “尔有嘉谋嘉猷……曰‘斯谋斯猷，惟我后之徳’”）。本份没有用「」『』。
- “某曰”“某云”后接整句引语，用冒号加引号；“故曰”“谓”“所谓”“称”后只引一个词组或半句、作宾语的，不加冒号（如 故曰“比屋可封”、《书》称“为学逊志”）。原稿全份一致，没有改。
- 书名号：书名、篇名都加，几种书连写时各加一对，中间不加顿号（《诗》《书》《易》《春秋》、《语》《孟》、《国风》《雅》《颂》）；篇名单独加，不用间隔号（荀子《解蔽篇》、韩昌黎《守戒》、唐《百官志》）。“二典”“十翼”“戴记”“六经”不加。卦名（晋、泰、坎、离、否等）不加书名号。
- 原稿只有一处混用：卷二十三 0004“惟《春秋》、十翼、《论语》、《孝经》与戴记《中庸》《大学》等篇”，因中间夹着不加书名号的“十翼”，用了顿号，读得通，没有改。
- 指书的“易”作《易》：本轮补了两处（见下）。“易有太极，是生两仪”（卷二十 0012、0109）照原稿不加：《系辞》这句的“易”历来讲成变易之道，现代点校本多数不加；“四营成易”是变易义，也不加。lujiuyuanji-5 的统一规则是“指书的一律加”，这两处汇总时请一并定。
- “学诗”“闻诗闻礼”“兴于诗”（卷二十三 0005）原稿不加书名号，照杨伯峻《论语译注》的习惯，没有改。

原稿质量很好：没有发现句号落在句中、引号起止不对、人名地名官名被断开的地方。

## 原稿“拿不准”各条的判断

- 0239“不欲出似，却语及之”：同意。宋人口语“出似”就是“拿出来给人看”，下文“渠力索观，畧出示之”可以印证。
- 0253“如蛆蠧，如蟊贼，以自饱，适由君子观之”：同意。“饱适”不成词，“适”属下读，是“恰恰”的意思。
- 0259“凛焉朝夕，祈于斯民，𦕈若航海”：保持，𦕈字不明（疑“眇”），断法读得通。
- 0272“适直数日纷冗拨置，占复草草”：保持。“拨置”属上读，指杂事堆积。
- 0277“近有襄阳逃卒亦不少，有来者，寻至即令擒去矣”：保持；同段下句改成同样的断法（见上表）。
- 0281“今嵗亦幸，有湖北平时水浸，有不可种禾者，民皆种禾”：保持。句意大致是平时被水淹、种不了禾的低田今年都种上了；“湖北”指地名还是指湖北岸的田，定不了。
- 0283“异时所见武弁，不多其比，陶右下风者”：保持。“陶右”疑有误字，定不了。
- 0301“义勇之外，队火队今亦可恃”：保持。同段上文作“烟火队”，“队火队”疑有讹，照现文断。
- 0392“填星复顺，之入龙底，直二大星之间”：保持，“之”是“往”的意思。
- 0396“乃俾犹子谦之、槱之，子持之，分书同逰者……”：同意。“犹子”管“谦之、槱之”，“子”管“持之”（陆持之是象山的儿子，0277 有“小儿持之”）。
- 卷二十 0021“非有若私智杜撰者所可糊涂也”：保持，不断开。这一章用的是曾子拒绝事奉有若的典故，“有若”也可能指人，但照现文连读也通。
- 卷二十 0029 张释之语引号起讫：同意，和《史记·张释之列传》原文相合。
- 卷二十 0090“而牟年焉兴师伐滕”：保持，定不了。

## 仍拿不准、要请人看的

- 卷八 0339“熈寜排公者，大抵极诋訾之言，而不炳灵，殆不世有，其庙貌弗严”：“而不”和“炳灵”之间疑有脱文（通行本《荆国王文公祠堂记》在这里还有好几句），照现文只能勉强这样断。
- 卷八 0263“到此并无一字掲示，无随行人一榜，亦吏呈旧比从之”：也可以读作“无随行人，一榜亦吏呈旧比从之”，两种都通，保持原稿。
- “易有太极”是否加书名号，见体例说明。
