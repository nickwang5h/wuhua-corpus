# 维基文库悬浮异文注混入正文（tooltip）

方法：语料库导入时缓存的渲染 HTML（wuhua-corpus/.cache/wuhua-corpus/pages/<revision>.json，即导入所用的同一版本）里，逐页找 `class="variant-text"` 下的 `class="variant-tooltip"`（{{另}}、{{另2}}/{{參}} 都渲染成这个结构，见 Template:另、Template:另2 源码），取出“甲＋悬浮文字”，到该书同出处章节的现有正文里找。找到的就是混入的模板注，删去悬浮文字、保留甲。另用正则（一作/一本作/又作/或作/一云/本作＋引号）扫全库，没有对上模板的，逐条看来源，归为底本校语或正文，不动。抽查：孙子 oldid=7906064 的维基文本为 `勝可{{另|擅|為}}也`；朱子語類维基文库本作“只溫熱一作「煖」。之氣”“【一作「只是理」。】”，是底本小注；元豐類稿卷三十五维基文库本作“至三〈一作一二〉百”，是底本小注。
