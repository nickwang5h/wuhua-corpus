## 中文首页与阅读

首页只以蝴蝶、完整引文、出处和实际阅读入口开场：

> 周与胡蝶，则必有分矣。  
> 此之谓物化。
>
> 《庄子·齐物论》

保留“胡蝶”、完整两句与标点，不另写宣传语。“物化”使用重点色 accent，并以上方 ruby 标注 wù huà，随日夜配色变化。引文上限 760px，桌面 40px、手机 28px，行高 1.6，两句间换行；手机第一句自然折行。开场上下 padding 桌面 32／40px、手机 24／32px；蝴蝶 88×66px，距引文 16px，引文距出处 12px，出处距按钮 24px。按钮为接着上次读／打开书架。今日推荐独立放在其后，只在有已审核候选时显示，不用准备中占位。

书架横排／手机单列、宋体与阅读设置保持。正文上限 720px，短摘录（不超过 100 汉字且不是整章）居中，长文与说明左对齐。短摘录上下 padding 改为 28／20px；字号设置继续生效。清读／解读／回味和下方解读、笔记沿用，无常驻旁栏。

## Learn 页面约定

使用现有日夜色彩、英文系统字体、标题 Georgia 和中文文楷。首屏以 “A few words. A new way to see.” 开场，给出一个直接 Read 的推荐，不把古文、选级别或完成进度放在阅读入口前。

| 区域 | 当前职责 |
| --- | --- |
| 顶栏 | Wuhua Learn、Home、Explore、Saved、Settings、英文可访问名称的主题开关 |
| Settings | Source edition / Simplified / Traditional、三档字号、System / Light / Dark、Show pinyin |
| Home | 简短介绍、编辑推荐、Explore more；一个推荐用 soft 底色，其余为普通文章列表 |
| Explore | 标题／摘要搜索和文章列表；无课程序号、前置条件或完成徽标 |
| Reading header | 页面唯一 h1、摘要、Starting / Building 和预计分钟数 |
| MDX body | 普通段落、二级起的标题、列表与强调；无固定内容模块或强制阶段 |
| Phrase | 中文词句、可隐藏的显式拼音、英文解释；现代例句可直接编写 |
| ClassicQuote | 段落版本与范围解析的原文、对齐拼音、固定来源链接 |
| 文末 | 可展开的 Sources and editorial notes、Save reading、可选引句分享打印、A note to keep、相关推荐 |
| Saved | 新旧收藏和笔记、旧引用快照与未提交草稿、完整备份恢复 |

文章正文上限 680px，桌面基准 19px、手机 18px，行高 1.85，跟随字号设置。标题与摘要独立于正文；文章能使用任意数量的段落或小标题。Phrase 以简单竖线区分例句，经典出处嵌入正文需要的位置，不做强制开场。

手机使用单列和自然折行；导航独立一行，品牌、设置与明暗开关保持可达。文章不出现 Continue / Finish / Next question、三段进度或课程序号。不要为了保持旧样式而保留课程 CSS。

普通文字链接带清晰指示；文章卡片标题可整行链接，hover 显示下划线。正文来源、审核状态和外部材料放在统一来源区域，不让作者复制 UI 标记。

## 共享原文动作

中文站保持 PassageActions。Learn 的 Save reading 保存文章，Share a quote / Print a quote 作用于经典节选，文案明确区分对象。没有经典来源时不显示引句动作。多来源文章通过现有分享／打印面板选择原句。

PNG 在字形转换、字体就绪和测量折行后生成；弹窗预览与下载为同一 Blob。字帖先站内分页预览，再系统打印；A4 / Letter、整句／单字／节选、描摹及空白行沿用通用实现。整句不去重，缺拼音不猜读音。

## 验证基线

修改 Learn 布局时检查 390px / 1440px、日夜模式、大字号、正文与长引用的宽度。核对首页 → Explore → 任意 Reading → Saved，以及错误重试和设置保存。使用合成旧记录验证新操作与完整导出保留旧数据。

分享或打印调用变化时打开实际产物；来源与正文变化时对照共享文本及码点范围。中文共享组件或内容层变化需回归对应中文路径。验收事实追加 worklog，旧截图只作历史记录。
