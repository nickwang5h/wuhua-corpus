## 中文首页与阅读

首页只以蝴蝶、完整引文、出处和实际阅读入口开场：

> 周与胡蝶，则必有分矣。  
> 此之谓物化。
>
> 《庄子·齐物论》

保留“胡蝶”、完整两句与标点，不另写宣传语。“物化”使用重点色 accent，并以上方 ruby 标注 wù huà，随日夜配色变化。引文上限 760px，桌面 40px、手机 28px，行高 1.6，两句间换行；手机第一句自然折行。开场上下 padding 桌面 32／40px、手机 24／32px；蝴蝶 88×66px，距引文 16px，引文距出处 12px，出处距按钮 24px。按钮为接着上次读／打开书架。今日推荐独立放在其后，只在有已审核候选时显示，不用准备中占位。

书架横排／手机单列、宋体与阅读设置保持。正文上限 720px，短摘录（不超过 100 汉字且不是整章）居中，长文与说明左对齐。短摘录上下 padding 改为 28／20px；字号设置继续生效。清读／解读／回味和下方解读、笔记沿用，无常驻旁栏。

当前五课均可独立学习，prerequisites 为空。课程开场围绕本句展开；同书、相邻章节、目录顺序和共用字词属于内容关系，学习依赖应有明确的必要知识依据。未来确有先修需求时，先核实本课缺少哪项必要知识，再在选课处说明。

Read 调用同一 LessonPassage，完整包含原句、Meaning、Words to notice、context 与底部 Save／Share／Print，开场直接提供独立英文释义及词义；intro 保留为已有内容字段，不在当前页面混合替代这两节。goal 用在课程卡与学习回顾。两节标题均为 18px，正文桌面 18px／手机 17px，英文沿用系统字体、行高 1.8；中文例字均使用学习文楷，署名使用 14px 次要文字。通用拼音知识由 Reading aids 承接。阅读页提供完整阅读模块，词义讲清本句实际用法，背景补充理解所必需的上下文；三者各自提供信息。

原句与辅助始终引用同一处底文及节选范围，开场、Read、练习回看、分享、打印都对照该引用。字形名称为 Source edition／Simplified／Traditional；内部 original 值兼容旧设置。Read 以一套当前字形呈现，中文教学改写继续保持独立数据身份。

原句 padding 24／18px，阶段标记 margin 16px 0 8px，草稿标记下间距 12px。页面随内容增高，字号设置与拼音行距继续有效。Read 的 Save／Share／Print 统一位于内容末尾（context 之后、Back／Continue 之前），由共享 PassageActions 渲染。两站复用按钮、图标、文字状态与样式，由各自页面传入保存／分享／可选打印动作。Save／Share／Print 使用图标与文字、至少 44px 触点，直接可见，Continue 保持主操作。Saved 以实际持久化成功为依据。

### 每课编辑后的走读

1. 从 Read 打开真实单元，确认标题、原句、拼音、出处、Meaning 和 Words to notice 共同指向本课内容；确认本课所需知识在当前课程中提供。
2. 到 Read 对照原文、Meaning、Words to notice、context 与具体来源；逐个问：这一项给初学者增加了什么必要信息？删除同义重复，补上学习所需解释。
3. 用英文引导完成两题；把每题正确答案及反馈对应回已展示的材料。答错、重试、返回、刷新后仍能继续。
4. 到 Reflect 检查回想确实围绕本句，保存合成笔记并重新进入，核对笔记、首次尝试与完成记录。
5. 纯新增课程核对本课引用与辅助数据接入；设置、保存、分享、打印的交互回归在公共组件或调用契约变化时执行，新数据形态按具体样例补测。
6. 在手机和桌面查看实际页面与截图，检查文字、按钮、折行及重复内容。记录教学内容判断、程序检查、浏览器行为验证各自的结果；人工审核按实际审阅者和范围填写。

当前五课内容审核字段仍为 draft，已按授权公开；页面移除开发 preview／draft 标签，Sources 如实显示状态。具体编辑复核与浏览器证据见 [worklog](worklog.md)。本表描述现行页面职责，历史改动与旧版验收由工作记录保存。

## Share：一张真实 PNG

面板上限 960px，桌面预览优先，手机先图片后控件。打开就生成实际 PNG，下载直接使用同一 Blob／object URL。加载字体、字形或生成期间禁用下载；每次节选／字形／主题改变废弃旧结果，关闭和更新释放 URL。失败可重试生成及复制文字；浏览器缓存失败字体时需重新加载。

宽度 900px，高度按实测字体与行数计算；横 padding 64px、纵 48px，原文 46／72px，出处 24／34px，品牌与链接 22／32px，区块间距 24px。短文居中，长文逐行测量，不把署名固定在底部；显式换行与连续节选校验、基本标点避行首。当前单句加课程名卡为 900×380px。超出浏览器安全画布范围时明确失败并请缩短节选，不静默裁切。

节选框默认两行、最多约四行后内部滚动；字形默认当前显示，可局部切换；Day／Night 实时重新生成。私人笔记、英文 Meaning、拼音不自动进入图片。品牌按站点区分；地址必须由调用方提供，学习草稿不含正式课链接或 localhost。多段课程必须先选一段，生成与下载前不默认取第一段。

## Print：独立字帖预览

Read 的 Print 打开面板，不立即系统打印。上限 1080px，桌面 260px 设置栏＋纸张；手机全屏、设置在上、纸张在下，打印按钮处于正常文档流，不遮住内容。

- Full passage 默认：原顺序、重复字及标点全部保留；按范文／描摹／空白行组织，标点占格并避免因折行落行首。
- Individual characters：仅此模式去重汉字、去标点；默认一范字、两描摹格、三空白格。设置明确为 squares，按位置生成 key。
- Selected text：连续节选，同整句模式；相同节选多次出现时可选具体出现位置，保持拼音对应原位置。

字形默认阅读值，局部调整不写全站设置；描摹 0／1／2 行、空白 1／2／3 行；格子 12／15／18mm；A4／Letter；拼音默认关、中线与标题出处默认开。仅显示现有可用位置对齐的单字拼音，缺失或多字 token 不拆猜，留空。草稿拼音仍标未审核。

预览和系统打印复用同一分页数据和纸张组件，显示真实页数。15mm 边距、白底黑字、描摹 #B3B3B3；练习组完整分页，不截断行。字体就绪才打印；取消与关闭不更新学习进度。系统窗口可保存 PDF。

## 真实样例对设计的检验

本节保留设计阶段的真实样例与预期。已执行的新版浏览器验证见 worklog；教学审核仍单独记录，不能与流程验证混为一谈。

| 样例／证据 | 按方案走通的路径 | 本轮判断及实施须证实的结果 |
| --- | --- | --- |
| 《论语·学而》首段，`ws-lunyu-2058123-1-1-1` 起；原段见 fulltext.json | 中文从目录读完整引语，按需开词义；学习 Starting 只取目标短句、英文预引导、词义选择、反馈与继续 | 当前自动分句把左引号留在第一句，证明“句子即页面”不足；新阅读以段落维持语境，学习摘引明确范围 |
| 同段“學而時習之，不亦說乎？” | 原貌、简体显示和拼音对照；“說／说”的候选读音用人工覆盖为 yuè，按 joy 的语境解释；其余多音字也须逐 token 审阅 | 此读音和英文仍是待审核教学样例；“说”不可直接按现代默认读音生成。无审核拼音时中文缺项提示，学习单元不得进入可开始目录 |
| 《庄子·逍遥游》首段“北冥有魚……”至“乃今將圖南”，fulltext.json | 中文连续长段，目录定位、放大、写短笔记、离开续读；学习不把整段塞进首课，只引用短范围并配英文语境 | 可容纳原段的长短差异；须在手机、大字、打开辅助及软键盘下证实无溢出和位置漂移 |
| 《庄子·缮性》“由(之)[是]觀之”，`ws-zhuangzi-9853803-16-8-6` | 原貌保留校订符号；可读辅助说明符号，显示转换有明确映射 | 不删除符号冒充底文；符号无拼音，疑点不静默改字；本次未作校勘结论 |
| 任一新全文段（当前 terms／translation／thought 均空） | 中文仍可读、收藏、记问题；学习缺必需英文的单元只预览，回选课可找已审核单元 | 中文可缺解读与学习必须有足够辅助是不同规则，不能共用同一“空解释”页面 |
| 旧精选 z1“天地与我并生……” | 旧 deep link 和笔记显示旧文字，提示底本未核实；关联新版前先人工核对 | 保留历史而不伪称其来自当前 Wikisource；旧草稿解读不能自动升级 reviewed |

零基础单元的具体设计走查：英文说明 learning／practice → 配对“学”和 learn、“习”和 practise → 展示短句及其英文意义 → 选择该句强调“return to practice”而非“一次读完” → 错选时解释后重试 → 回顾并保存。输入汉字、独立翻译文言文和已有文化背景都不是前提；自动通过这个流程仍不能证明教学有效，首发需人工检查语境与学习目标。

### 可丢弃记录的变更推演

使用合成记录 N1（草稿“问题甲”、已保存“理解甲”）、N2（“理解乙”）、收藏 B1、位置 R1 和完成 U1，不接触真实笔记。原文样例取“學而時習之，不亦說乎？”，身份为临时 fixture `p-a@1`；以下是验收的输入／预期，不宣称迁移器已实现。

| 输入变更 | 必须得到的输出 | 可明确失败的条件 |
| --- | --- | --- |
| `p-a@1 → p-a@2` 改标点 | N1 保留 @1 文字，提示新版；B1／R1 仍可进入历史并选择新位置 | 笔记被无提示绑定新文字 |
| p-a 拆成 p-b、p-c；N1 为整段笔记 | N1 仅一条，旧段仍可读，显示两个后继；精确范围收藏映射需有审核依据 | 笔记复制两份／只落第一段／按序号猜测 |
| p-b、p-c 合为 p-d，各有 N1、N2 | 两记录保留各自旧引用和文本，可定位新段中的各自范围 | 同目标 ID 导致一个覆盖另一个 |
| 段落撤回或映射缺失 | 记录出现在历史引用／待关联；JSON 与 Markdown 仍有私人文字 | 页面空白、unknown ID 被过滤、无法导出 |
| U1 v1 已完成，v2 换核心练习 | 显示 v1 已完成和 v2 可复习，旧答案指向 v1 | 将旧答案当新题答案或清零历史 |
| 存储满／恢复冲突／坏 JSON | 未保存提示、会话可导出、现有存档不变 | 成功 toast 或用空数据覆盖 |

设计阶段用旧 parseStore 复现了 unknown ID 过滤问题。当前迁移器、历史映射与导出测试已另行实现，实际结果见 worklog，不以这张预期表冒充执行证据。
